# Nest & Nook Storefront

A modern dropshipping storefront for household organization products.

## Features
- Responsive storefront landing page
- Product catalog with filtering
- Shopping cart sidebar
- Mobile-friendly layout
- Ready for Stripe, Shopify, or custom checkout integration

## Run locally
Open `index.html` directly in a browser, or serve the folder with a local web server:

```bash
python -m http.server 8000
```

Then visit: http://localhost:8000

## Customize
- Update product names, pricing, and categories in `script.js`
- Adjust colors and layout in `styles.css`
- Modify branding and page structure in `index.html`
